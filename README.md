# Streamlit Components Demo

Live showcase of four custom Streamlit components by [Dan Sheils](https://github.com/RhythrosaLabs).

**[Launch the app on Streamlit Cloud →](https://streamlit-components-demo.streamlit.app)**

---

| Component | Description | Install | Repo |
|-----------|-------------|---------|------|
| **📋 Kanban** | Drag-and-drop board with columns, cards, tags & priorities | `pip install streamlit-kanban` | [GitHub](https://github.com/RhythrosaLabs/streamlit-kanban) |
| **🎛️ Audio Editor** | Waveform editor with full effects rack (EQ, filter, compressor, delay, chorus, distortion, tremolo, reverb, pan, speed), mic input & jam-session recording | `pip install streamlit-audio-editor` | [GitHub](https://github.com/RhythrosaLabs/streamlit-audio-editor) |
| **🪜 Stepper** | Multi-step wizard with typed fields, validation & animated progress | `pip install streamlit-stepper` | [GitHub](https://github.com/RhythrosaLabs/streamlit-stepper) |
| **🔗 Node Editor** | ComfyUI/Blueprints-style node graph with typed ports, drag-to-connect & inline params | `pip install streamlit-node-editor` | [GitHub](https://github.com/RhythrosaLabs/streamlit-node-editor) |

## Install all four

```bash
pip install streamlit-kanban streamlit-audio-editor streamlit-stepper streamlit-node-editor
```

## Run locally

```bash
git clone https://github.com/RhythrosaLabs/streamlit-components-demo.git
cd streamlit-components-demo
pip install -r requirements.txt
streamlit run app.py
```
